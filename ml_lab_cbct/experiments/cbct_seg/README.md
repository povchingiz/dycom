# Эксперимент CBCT-1 — Сегментация костей/зубов на ToothFairy3 (nnU-Net)

Первый рабочий артефакт твоего FEA-пайплайна. Выбран потому, что это **единственное направление, под которое у тебя есть данные прямо сейчас** (ToothFairy3 публичный). Калибровка материала (1.3) ждёт пар «до/после»; ML-сегментация мягких тканей (1.1) ждёт разметки кожи, которой в ToothFairy3 нет. Кости/зубы — есть, метрика есть, запускается на L40 сегодня.

## Зачем это в пайплайне
Хорошая костная сегментация → хороший меш (Gmsh/TetGen) → честная FEA. Это фундамент. Навык (3D-сегментация, nnU-Net, Dice, абляции под железо) переносится на мягкие ткани и калибровку, когда появятся твои данные.

## Научный цикл (как в твоих глубинных экспериментах)
1. **Гипотеза на бумаге** (до запуска): у тебя L40 48 ГБ против RTX 4090 24 ГБ, на которой бьют SOTA. Прогноз: увеличенный patch size использует больше пространственного контекста → выше Dice на крупных структурах и точнее нумерация зубов. Запиши ожидаемый прирост ДО прогона.
2. **Предсказание метрики**: baseline nnU-Net ResEnc ~0.90–0.92 Dice (по литературе ToothFairy2). Твоя абляция patch size: ожидаешь +X. Запиши X.
3. **Эксперимент**: обучить baseline + 1 абляцию на L40.
4. **Сверка**: совпал ли прирост с предсказанием? Если нет — почему (узкое место не в контексте, а в данных/классах?).
5. **Запись**: таблица «конфиг → предсказание → Dice → сошлось».

## Метрика (тестируемость артефакта)
- **Dice** per-class и mean на held-out (9:1 сплит, как в литературе).
- **HD95** (Hausdorff 95%) — чувствителен к границам, важен для качества будущего меша.
- Артефакт = чекпоинт + `metrics.json` + таблица абляций. Без метрики на held-out это не артефакт.

## Железо
SOTA-команды: RTX 4090 (24 ГБ), patch 128×256×256, batch 1, nnU-Net ResEnc.
Твоя L40 (48 ГБ): запас ~2x по памяти → первая осмысленная абляция = больше patch / batch.

## Порядок запуска
```bash
# 1. Окружение (один раз)
bash scripts/00_setup_env.sh

# 2. Данные — требуют РЕГИСТРАЦИИ (вручную, см. ниже)
#    Скачать ToothFairy3 с https://ditto.ing.unimore.it/toothfairy3/
#    (нужен аккаунт), положить в data/raw/
python scripts/01_prepare_data.py --raw data/raw --out data/nnunet

# 3. Smoke-test на CPU (1 батч) — ОБЯЗАТЕЛЬНО до GPU
python scripts/02_smoke_test.py --dataset 301

# 4. Обучение baseline (ночь на L40)
bash scripts/03_train.sh 301 baseline

# 5. Абляция patch size (следующая ночь)
bash scripts/03_train.sh 301 large_patch

# 6. Оценка на held-out → артефакт
python scripts/04_evaluate.py --dataset 301 --configs baseline large_patch
```

## Данные: важное про доступ
- ToothFairy3 под лицензией CC-BY-NC-SA, требует регистрации на ditto.ing.unimore.it.
- Формат: NIfTI, 0.3мм изотропно, Hounsfield Units.
- Скрипт `01_prepare_data.py` НЕ качает за тебя (нужен логин) — он конвертирует скачанное в nnU-Net формат.
- Сеть на этой машине ограничена; реальное скачивание и обучение — на твоей машине с L40.

## Что внутри
- `scripts/00_setup_env.sh` — установка nnU-Net v2, MONAI, зависимостей
- `scripts/01_prepare_data.py` — конвертация ToothFairy3 → nnU-Net формат, 9:1 сплит
- `scripts/02_smoke_test.py` — 1 батч на CPU, проверка пайплайна
- `scripts/03_train.sh` — обучение, выбор конфига (baseline / large_patch)
- `scripts/04_evaluate.py` — Dice/HD95 на held-out, запись metrics.json
- `configs/` — baseline и абляционные конфиги
- `notebooks/cbct_seg_guide.ipynb` — тонкий гайд: гипотеза → запуск → сверка
