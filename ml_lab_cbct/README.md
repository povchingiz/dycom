# План-привязка: Understanding Deep Learning (Prince, v5) → твоя ML-лаборатория

**Решение по структуре:** идём по ТВОИМ слоям, главы книги подбираем под них (не по порядку 1→21). Книга — мясо на твой скелет, а не сам скелет. Так получается твоя карта понимания, а не пересказ авторской.

**Ресурс:** L40 (48 ГБ), ~15 дней GPU. Книга: бесплатный PDF (v5, главы 1-21), 68 ноутбуков с TODO, авторский задачник с решениями.

**Важно про Слой 1:** книга закрывает его глубже, чем казалось. Глава 5 = MLE→loss (твоя центральная идея), глава 6 = оптимизация + гессиан/выпуклость. Доверительные интервалы через информацию Фишера книга подводит вплотную (задача 6.2 про гессиан) — финальный шаг (обратить гессиан → CI) достраиваешь сам. Это твоя авторская добавка, отличающая от учебника.

---

## Трёхуровневая система работы с ноутбуками

**Уровень 1 — направляемый.** Книжный ноутбук как есть: заполняешь TODO, отвечаешь на встроенные вопросы-предсказания. Цель — механика, быстро, без артефактов. → Слой 2 (карта парадигм).

**Уровень 2 — расширенный.** Книжный ноутбук + твоя надстройка: добавляешь markdown с выводом loss из MLE, строишь CI на параметры, обучаешь до сходимости, **сохраняешь чекпоинт** (книжные ноутбуки артефактов не дают). → Слой 3 (глубокие шурфы, рождаются модели-артефакты).

**Уровень 3 — авторский.** Твой тонкий ноутбук + `.py` модули, с нуля. Темы вне книги или по-своему. → Слой 4 (проектная задача).

**Механика для У2-У3:** книжный ноутбук скачиваешь как стартовую точку, НЕ редактируешь оригинал — копируешь в `ml_lab/notebooks/`, оригинал держишь для сверки. Тяжёлый код (модель, train-loop, метрики, CI) выносишь в `.py` модули, ноутбук тонкий — нарратив + вызовы.

## Слой 3 — Глубокие шурфы (У2-ноутбуки, основная GPU-нагрузка)

1-2 модели до дна, полный цикл с абляциями и артефактами. Рекомендация: трансформер + свёрточная.

### Шурф A — Трансформер (глава 12)
- Ноутбуки Chap12. Реализовать attention, понять self-attention.
- Абляции: число голов, глубина, hidden size → предсказание из теории, потом проверка.
- Оптимизация: Adam vs SGD, warmup, LR-расписания (глава 6-7).
- **Артефакт:** обученный малый трансформер на NER/классификации + чекпоинт + таблица абляций.

### Шурф B — Свёрточная / Residual (главы 10, 11)
- Ноутбуки Chap10, Chap11. CNN, потом residual — зачем skip-connections.
- Готовый ноутбук абляций: **8.1 MNIST-1D Performance** (меняй слои, hidden, LR, batch, momentum) и **8.3 Double Descent** — поведение оптимизации/обобщения.
- Loss под сегментацию: вывести Dice vs BCE из предположений (авторское, вне книги).
- **Артефакт:** обученная CNN/U-Net + чекпоинт + таблица абляций.
